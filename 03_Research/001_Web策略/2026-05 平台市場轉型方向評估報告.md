## 一、我們希望的改變方向

我們目前擁有兩個主要專案：**APP**（原 Unity 開發的娛樂城）與 **WEB**（與 APP 共服的網頁版）。  
本次轉型涉及以下五個方向：

| # | 方向 | 說明 |
|---|---|---|
| 1 | **APP 與 WEB 拆開** | 兩個專案伺服器分離，獨立運營、各自金流 |
| 2 | **APP 由 Unity 轉為 Cocos，進駐 LINE 博弈市場** | 技術棧轉換，定位從娛樂城轉向 LINE 博弈平台 |
| 3 | **WEB 定位從娛樂城轉為現金網** | 功能、金流、目標用戶全面向現金網規格靠攏 |
| 4 | **新 API 遊戲由電子館上架至 APP 與 WEB** | 遊戲供應鏈統一管理，新遊戲雙平台共用 |
| 5 | **向海外市場販賣 WEB 站台** | 僅供外部廠商營運，可換外觀、決定遊戲上架與否 |

### 2.2 不同市場的目標客群及為何不互換

每種市場的玩家客群有根本性差異，以下說明各自在意的核心點，以及為何他們不會跨市場流動：

#### TW APP 娛樂城的玩家

**在意的核心：社交認同感、每日回訪動機、帳號成長感**

- 透過公會、好友、排行榜感受「在圈子裡的地位」
- 每日簽到、任務系統給予回訪的理由
- 頭像框、VIP 勳章帶來可見的帳號價值

**為何不會去現金網？**  
現金網缺乏社群功能，帳號沒有「身份感」，輕度玩家不願意經過 KYC 驗證，且出金流程複雜。

**為何不會去 LINE 博弈？**  
LINE 博弈功能太簡陋，沒有每日任務或公會，無法滿足「玩平台」的需求。

---

#### TW LINE 博弈的玩家

**在意的核心：快速進場、社群推薦信任感、佣金透明**

- 透過 LINE 群朋友推薦，信任感來自熟人背書而非平台本身
- 無需複雜註冊，掃碼即玩
- 代理幫忙解決出入金問題，玩家幾乎不直接與平台互動

**為何不會去娛樂城？**  
娛樂城需要下載 APP、完整註冊，對他們來說「太正式了」，且娛樂城沒有他們信任的代理連結。

**為何不會去現金網？**  
現金網需要 KYC，且必須自己處理銀行出入金，和習慣靠客服/代理的使用習慣完全不符。

---

#### TW 現金網的玩家

**在意的核心：出金保障、計價透明、帳號隱私**

- 投注金額大，最在意「輸贏算得清楚」和「出金得了」
- 不想讓人知道自己在賭，隱私優先，排斥社群功能
- 願意配合 KYC 換取出金保障

**為何不會去娛樂城？**  
娛樂城靠幣商出金，幣商詐騙風險高，大額玩家承擔不起。

**為何不會去 LINE 博弈？**  
LINE 博弈出入金完全靠客服/幣商，點數計價不透明，大額玩家不接受。

---

#### 海外亞洲現金網的玩家

**在意的核心：行動支付便利性、代理服務、返水回饋**

- 主要透過代理介紹入場，信任感來自代理而非品牌
- 偏好熟悉的行動支付（如 GCash、Momo）
- 返水是主要留存動力

**為何不會去台灣現金網？**  
語言、幣種、支付方式完全不同，且台灣現金網沒有當地代理網絡。

---

#### 其他州現金網（美洲/歐洲）的玩家

**在意的核心：合法性保障、免費試玩機會（SC）、大獎吸引力**

- SC 每日免費贈送，讓玩家在「不花錢」的心理下持續回訪
- 法律框架讓他們不擔心帳號被封或資金被凍結
- Jackpot 大獎是主要消費動機

**為何不會去其他市場？**  
其他市場的法律框架（灰色地帶）讓他們有法律風險疑慮；台灣市場的超商/電信入金對他們來說完全陌生。

### 2.3 結論：想成為各類型平台，需要哪些核心功能？

#### 如果要做 TW LINE 博弈

| 需要 | 原因 |
|---|---|
| LINE LIFF 入口 | 玩家透過 LINE 社群進入，不走 APP 下載流程 |
| 代理後台（含佣金計算） | 代理是主要獲客和留存機制 |
| 幣商對接 | 出入金靠幣商處理，官方不直接管現金 |
| 返水系統 | LINE 博弈玩家最主要的留存誘因 |
| 排行榜 | 社群競爭刺激 |
| 客服系統 | 代理和玩家的主要溝通管道 |

不需要：簽到、公會、頭像框、KYC、銀行出金

---

#### 如果要做 TW 現金網

| 需要 | 原因 |
|---|---|
| 銀行直接出入金 | 1:1 現金、平台負責，這是現金網的核心定義 |
| KYC 驗證（含綁定銀行帳號） | 出金保障的必要條件 |
| 出金審核後台 | 每筆出金需要人工或自動審核 |
| 反洗錢監測 | 合規需求，防止異常大額進出 |
| 返水系統 | 吸引大額玩家的主要工具 |
| VIP 等級 | 大額玩家在意排名與禮遇 |
| 真人視訊遊戲 | 現金網玩家主力遊戲類型 |
| 體育投注 | 現金網獨有，吸引特定客群 |

不需要：公會、好友、簽到、轉盤抽獎、幣商對接

---

#### 如果要做海外現金網（亞洲）

在 TW 現金網基礎上，額外需要：

| 需要 | 原因 |
|---|---|
| 代理後台 | 海外亞洲市場靠代理獲客 |
| 多國行動支付對接 | GCash（菲律賓）、Momo（越南）、PromptPay（泰國）等 |
| 多語言界面 | 至少英文 + 目標國語言 |
| 地區驗證 | 限定特定國家用戶登入 |
| 多幣種支援 | THB、PHP、VND、USD 等 |

---

#### 如果要做海外現金網（美洲/歐洲）

在 TW 現金網基礎上，額外需要：

| 需要 | 原因 |
|---|---|
| SC / GC 雙幣系統 | 美洲合法框架的核心，缺少此設計等同違法 |
| 每日免費 SC 贈送機制 | 讓玩家不花錢也能回訪，是日活的主要驅動力 |
| 強制 KYC + 地區鎖定 | 各州法律不同，鎖定合法州才能運營 |
| 自我排除（Self-Exclusion）功能 | 歐美法規要求，玩家可申請停用帳號 |
| 信用卡 / Apple Pay / Google Pay | 歐美主流支付，無超商/電信選項 |
| 責任博弈提示 | 界面須有法規要求的警示文字 |

## 三、為何要做此改變（目前遇到的危機與風險）

### 3.1 WEB 對 LINE 博定位尷尬：共服造成金流互相污染

LINE 博弈是介於娛樂城（幣商制、重活動）與現金網（直接金流、輕活動）之間的特殊型態。

**目前的問題**：WEB 與 APP 共用伺服器，APP 發放的平台贈幣（簽到、活動）會流入 WEB，影響 WEB 的水位平衡，反之亦然。

具體問題如下：

| 問題 | 說明 | 後果 |
|---|---|---|
| 贈幣水位互相干擾 | APP 活動發出的平台幣，玩家在 WEB 消費，造成 WEB 帳面虧損 | 無法獨立評估 WEB 的真實獲利 |
| 活動邏輯無法分離 | APP 的簽到、任務活動連動到 WEB，WEB 的現金網定位無法被貫徹 | 無法做出「輕活動、重金流」的現金網體驗 |
| 拆帳不清 | 共服下無法區分 APP 與 WEB 各自的充值額、利潤、成本 | 每月財報無法說清楚哪個版本賺了多少 |
| 風險無法隔離 | 某一端的異常行為（套利、異常充值）會影響另一端 | 風控困難 |

**根本解法**：拆開伺服器，金流各自獨立。

---

### 3.2 我們需要現金網站台，切入現金網市場

目前我們的兩個專案都在「幣商制」的灰色地帶運營，存在以下風險與限制：

| 現況問題 | 說明 |
|---|---|
| 利潤來源模糊 | 遊戲利潤難以從幣商佣金中獨立計算 |
| 幣商依賴風險 | 幣商跑路或不配合，影響整個平台出金信譽 |
| 無法吸引大額玩家 | 大額玩家不信任幣商制，只願在有保障出金的現金網投注 |
| 無法向海外販賣 | 海外廠商需要真實金流架構，幣商制無法在海外合規運營 |

**現金網是我們切入更高 ARPU 客群、向海外擴張的必要基礎建設。**

---

### 3.3 販賣站台帶來的新分潤模式

目前我們的收入來自平台直接運營。向外販賣 WEB 站台，會引入全新的分潤結構：

| 分潤模式 | 說明 |
|---|---|
| 系統授權費（一次性） | 外部廠商購買站台使用權 |
| 年費 / 維護費 | 持續的技術支援與系統更新費用 |
| 遊戲流水分潤 | 廠商透過我們的電子館上架遊戲，按流水抽成 |
| 後台數據服務費 | 廠商使用我們的報表、代理工具、風控系統，收取服務費 |

這個模式的意義：

```
原本：我們運營平台 → 我們賺玩家的錢
改變後：廠商運營平台 → 廠商賺玩家的錢 → 我們賺廠商的錢
```

一旦建立，可以快速複製到多個廠商，不再受限於自身運營能量。

## 四、如何落實此改變

### 4.1 拆開 APP 與 WEB 的伺服器

拆分的核心目標是讓兩個專案完全獨立運營，互不影響：

| 拆分項目 | 說明 |
|---|---|
| 帳號系統分離 | APP 與 WEB 玩家資料各自獨立，不共用同一張資料表 |
| 金流分離 | 各自有獨立的入金帳戶、出金流程、幣種計算 |
| 活動系統分離 | APP 的贈幣活動不再影響 WEB 水位，反之亦然 |
| 財務報表獨立 | 各自有獨立的日/週/月收益統計 |
| 後台分離 | 各自有獨立的管理後台，運營人員只看自己負責的版本 |

拆分後，兩個專案透過**保險箱機制**在主系統層面連接，方便總帳管理，但各自風險完全隔離。

---

### 4.2 將 WEB 平台功能向現金網規格開發

根據第二章的市場分析，WEB 轉型為現金網需要以下功能方向的調整：

| 功能方向 | 改造前（娛樂城共服） | 改造後（現金網） |
|---|---|---|
| 出入金 | 幣商處理，官方不直接負責 | 平台直接 1:1 銀行出入金 |
| 帳號驗證 | 無強制驗證 | KYC 強制（身份、年齡、銀行帳號綁定） |
| 活動 | 沿用 APP 的豐富活動（簽到、任務等） | 精簡為返水、VIP 禮遇、排行榜 |
| 社群功能 | 沿用 APP 的公會、聊天 | 移除（現金網玩家重隱私） |
| 遊戲品類 | 虎機、棋牌、魚機 | 擴增真人視訊、體育投注 |
| 風控 | 基礎異常監測 | 反洗錢監測、出金審核、操作日誌強化 |
| 後台 | 共用後台 | 獨立後台，含完整金流管理 |

**海外版本的額外調整（依目標市場）**：

| 市場 | 額外需要 |
|---|---|
| 海外亞洲 | 代理後台、多國行動支付、多語言、地區驗證 |
| 美洲 / 歐洲 | SC/GC 雙幣系統、自我排除、責任博弈提示、強制地區鎖定 |

---

### 4.3 為外部營運商準備的後台工具、報表與分帳機制

外部廠商購買 WEB 站台後，需要能夠自行運營，因此我們需要提供：

#### 後台工具

| 工具模組 | 功能說明 |
|---|---|
| 玩家管理後台 | 查詢玩家資料、凍結帳號、手動調整餘額 |
| 出入金管理 | 查看所有出入金申請、審核、批准、轉帳紀錄 |
| 代理後台 | 管理代理層級、計算佣金、追蹤下線玩家 |
| 活動管理 | 設定返水比例、VIP 禮遇、排行榜活動 |
| 遊戲上架管理 | 決定哪些遊戲顯示在前台（開/關遊戲） |
| 客服工具 | 查看玩家聊天記錄、處理申訴 |
| 風控監控 | 異常交易告警、大額進出金警示 |

#### 報表數據

| 報表類型 | 包含內容 |
|---|---|
| 財務日報 | 當日充值額、出金額、遊戲流水、平台利潤 |
| 玩家行為報表 | 日活躍人數、新增玩家、留存率、平均 ARPU |
| 遊戲報表 | 各遊戲的流水、RTP、玩家偏好 |
| 代理報表 | 各代理的拉新數、下線流水、應付佣金 |
| 異常報表 | 可疑交易清單、被凍結帳號清單 |

#### 分帳模式

外部廠商運營我們的 WEB 站台，分帳邏輯如下：

| 收費項目 | 計算方式 | 說明 |
|---|---|---|
| 系統授權費 | 一次性固定費用 | 依功能規格（基礎版 / 進階版）定價 |
| 遊戲流水分潤 | 月遊戲流水 × 分潤比例（例：3-8%） | 廠商每月結算，自動從後台扣除 |
| 年費 / 維護費 | 固定年費 | 包含系統更新、技術支援 |
| 後台服務費 | 可選，依使用量計費 | 進階報表、風控模組等增值服務 |

**分帳流程示意**：

```
玩家在廠商平台遊戲
    ↓
月底統計遊戲流水
    ↓
我方從流水中抽取分潤（例 5%）
    ↓
剩餘流水利潤歸廠商
    ↓
廠商另外支付年費和維護費
```

### 4.4 三個站台的運營方式差異

改造完成後，我們將同時運營三個性質不同的站台，各自有獨立的目標客群和運營邏輯：

| 維度 | APP（LINE 博弈） | WEB（現金網，自營） | WEB（現金網，外部廠商） |
|---|---|---|---|
| **目標客群** | 台灣 LINE 社群玩家 | 台灣 / 亞洲大額玩家 | 依廠商目標市場（亞洲 / 美洲等） |
| **獲客方式** | LINE 社群推薦、代理 | 廣告、SEO、代理 | 廠商自行負責獲客 |
| **金流方式** | 幣商制（官方收佣金） | 平台直接銀行出入金 | 平台直接銀行出入金（廠商管） |
