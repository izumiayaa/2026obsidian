# 豪神 規格規則整理

> 依《慶宜ㄉ競品平台活動》各分頁中「豪神」相關內容彙整，共涉及 15 項平台活動規格。原始資料另見 [[300_目錄|平台活動規格目錄]]。

## 人拉人

- 好友升等你拿獎橫幅，含專屬邀請碼、邀請好友/助力好友/好友列表按鈕及App下載QR code
- 1. 邀請好友
- 發送自己的邀請碼給好友，好友獲取遊戲並綁定手機門號，輸入你的邀請碼，成功邀請好友數即可 +1。
- 2. 助力好友
- 等級達到5級之前，綁定手機門號，輸入好友的邀請碼，即可成功助力好友。
- 注意： 同裝置若創立多個帳號，將無法輸入邀請碼。
- 3. 領寶箱
- 每成功邀請 5位好友，即可領取寶箱獎勵 50,000 豪幣（此獎勵可重複獲得）。
- 4. 查看已邀請好友列表
- 好友達成等級 — 可獲得獎勵 (豪幣)
- 20級 — 20000
- 50級 — 50000
- 100級 — 100000
- 500級 — 200000
- 1,000級 — 500000
- 如果您成功邀請了 5 位好友，且這些好友的留存與活躍度不同，您的預期收益為：
- 保底流失型： 5人都只完成綁定，沒怎麼玩
- 領取一個寶箱 = 50,000 豪幣
- 輕度玩家型： 5人都玩到 100 級 — 著重「大戶」養成： 這套規格非常鼓勵老玩家去帶新玩家，尤其是 Lv.500 以後的獎勵跳幅很大（從 20萬 跳到 50萬），能有效激勵邀請者輔導新手留存。
- 1個寶箱 (50k) + 5人 × 累計獎勵 (170k) = 900,000 豪幣
- 核心骨灰型： 5人都衝到 1,000 級
- 1個寶箱 (50k) + 5人 × 累計獎勵 (870k) = 4,400,000 豪幣

- 推薦好友頁，我的介紹人/已邀請人數，等級達Lv50可開通邀請碼並分享
- 各獎勵最多20份
- 玩家手機綁定 — 10000
- LV5 — 5000
- LV15 — 10000
- LV30 — 30000
- LV50 — 60000
- LV75 — 120000
- LV100 — 200000
- 押注升等

## 回歸任務

- 回歸禮遇，活動剩餘9天，已簽到打卡，第1日任務，累積押分達等級解鎖大獎，一鍵領取

## 免費贈幣

- 「週1開寶箱」轉輪抽獎活動，含押分需求10,000、已領取/开级/抽奖按鈕
- 1. 活動於本週五、週六、週日及下週一開放。
- 2. 本週五、週六、週日登入可領取一把銀鑰匙，通過完成任務可升級為金鑰匙。
- 3. 下週一為抽獎日，可使用鑰匙開啟寶箱。
- 4. 金寶箱必開出寶石及隨機獲得豪幣、道具卡獎勵等任一種獎勵，最高可獲得遊戲神卡。
- 5. 銀寶箱可隨機開出豪幣及道具卡獎勵等任一種獎勵。
- 6. 寶石累積達成條件後，將可獲得轉盤抽獎，最高可獲得遊戲神卡。
- 7. 未使用到的鑰匙於週二 0 點清零，寶石可以永久保留。
