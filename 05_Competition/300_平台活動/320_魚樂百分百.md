|  |  | 顯性消耗：在活動商城使用活動金幣兌換禮包 |  |  |  |  |

|  |  | 每日限量購買的「白銀禮包」（每日特惠）是強大的誘餌，利用「不買就是虧」的心理促使玩家每日務必完成最低限度任務 |  |  |  |  |
| 優點 |  |  |  | 優點 |  |  |

| 規格說明 |  |  |  |  |  |  |
|  |  | 核心玩法 |  |  |  |  |
|  | ● | 任務矩陣：依據廳館（財神捕魚、激鬥海皇等）與難度（簡單、普通、困難）區分。 |  |  |  |  |
|  |  |  | 簡單：無押注限制，獎勵少。 |  |  |  |
|  |  |  | 普通：中等押注限制（如 700分），獎勵中等。 |  |  |  |
|  |  |  | 困難：高押注限制（如 1,400分），獎勵高（約簡單的 10 倍） |  |  |  |
|  | ● | 代幣商城：累積活動金幣兌換「鑽金/黃金/白銀」禮包或特定卡包 |  |  |  |  |
|  | ● | 玩家吸引點： |  |  |  |  |
|  |  |  | 明確的目標感：相比純隨機掉落，任務制（打死幾隻給多少分）提供確定的獎勵預期。 |  |  |  |
|  |  |  | 每日特惠誘因：商城中有極低價的「白銀禮包」（1,000 金幣），通常隨便打個任務就能換到，屬於典型的「登入獎勵變體」。 |  |  |  |
|  |  |  | 道具卡回饋：兌換內容包含「特色卡」與「魚機卡」，這些道具能直接反饋到捕魚機的贏分體驗中。 |  |  |  |
|  | ● | 特殊機制： |  |  |  |  |
|  |  |  | 使用範圍技（如連環炸彈蟹、風暴魚）造成的「間接擊殺」不列入任務計數。這點非常關鍵，防止玩家利用範圍武器低成本掃台刷任務，強制要求玩家「點對點」擊殺 |  |  |  |
|  |  |  | 若使用加押砲（如烈魔砲），押注額判定是以「原始Bet」計算，而非加乘後的Bet。例如 Bet 20 開 3倍砲 = Bet 60，系統仍視為 Bet 20。這防止玩家利用加押砲輕鬆跨越任務門檻。 |  |  |  |
|  |  |  | 不同廳館的任務次數獨立計算（範例中提到小包在一般廳解完，還能去高手廳解），最大化玩家在線時間 |  |  |  |
