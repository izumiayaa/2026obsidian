## 二、兩條完全不同的成長曲線（討論時務必拆開）

把兩家混在一起講會得到錯誤結論。它們的形狀完全不同。

### 嚦咕：階梯式躍升，目前已在高原

```
2025-01  10.2M
2025-02  11.0M
2025-03  17.8M  ← 第一階開始
2025-04  28.2M  ← 兩個月翻 2.5 倍
2025-05~09  約 30M（橫盤 5 個月）
2025-10  36.3M
2025-11  44.5M  ← 第二階
2026-01~06  45.2 / 37.4 / 47.0 / 42.4 / 45.4 / 42.3  ← 2026 全年零成長
```

**兩次階梯，中間橫盤。2026 年已經停止成長。** 嚦咕是「單一事件驅動」型，要問的是那兩階各自踩到了什麼。

### 豪神：連續複利，至今仍在加速

```
2025-01  36.4M → 2025-12  49.1M → 2026-07  56.1M
```

19 個月緩坡爬升 +54%，**全市場唯一 2026 下半年還在創新高的品牌**，沒有任何一次明顯階梯。豪神是「持續機制」型。

### 集團內部結構變化

| 期間 | 豪神 | 嚦咕 |
|---|---|---|
| 2025H1 | 237M（65%） | 127M（35%） |
| 2026H1 | 300M（54%） | 260M（46%） |
| 2026Q3 | 56M（58%） | 41M（42%） |

嚦咕 2025 追上來後，2026 又被豪神拉開。**雙品牌不是平行擴張，是交替接力。**

## 三、成功因素（心智圖主幹）

### 主幹 1｜變現設計：把「儲值」本身遊戲化

這是兩家最強、也最反直覺的共同點。

**證據：儲值類活動密度全市場最高**

| 品牌 | 儲值檔數 | YoY |
|---|---|---|
| 豪神 | **34** | +26.5% |
| 嚦咕 | **25** | +104.3% |
| 老子 | 16 | +1.1% |
| 王牌 | 13 | -24.9% |
| 包你發 | 11 | -5.6% |
| 錢街 | 9 | +41.9% |
| 星城 | **2** | -11.5% |

**關鍵不在數量，在型態。** 別家的儲值活動是「折扣／加贈」，這兩家是「把付費行為做成一個有隨機獎勵的小遊戲」：

- 豪神：儲值小瑪莉、儲值滿額轉輪、滿購抽卡、豪運福袋、儲值福袋
- 嚦咕：金字塔探秘、暴富轉盤、幸運洞洞樂、驚喜抽抽樂、儲值小瑪莉-驚喜抽抽樂

**四個可拆的子機制：**

1. **隨機獎勵包裝** — 付錢的當下就有一次抽獎，把消費瞬間變成遊戲瞬間
2. **階段式／累積式結構** — 七日優惠禮（豪）、七日聚寶盆（嚦）、累積儲值、階段式禮包-端午送好禮。拉長付費週期，製造連續承諾
3. **限量稀缺** — 「110% 明日驚喜禮包（限 10 次）」，用次數上限製造急迫
4. **社交贈禮迴圈（豪神獨有，最值得抄）** — 收禮加速累積分 → 收禮積分爭霸 → 贈禮積分排行榜。**把儲值→送禮→競賽接成三段閉環**，讓付費有社交出口，避免純消費的空虛感

**外部通路綁定：** 全家、MyCard、GASH、藍新（綁官方 LINE）。兩家都在做，意義是繞過 IAP 30% 抽成 + 觸及不用信用卡的客層。

> 討論題：金好運目前的儲值活動是折扣型還是遊戲型？「商城金幣加贈 20%」重複出現三次，這是純折扣。

**豪神／嚦咕的內容策略拆三層：**

1. **正版原廠首發當品牌資產** — 嚦咕直接把「戰神賽特2首發登場」寫進 App Store 名稱，當 ASO 關鍵字用。兩家在搶同一批 ATG／RSG 首發窗口（ATG 古神巴風特：豪神 5/12、嚦咕 5/14）

   - 人流：新機轉盤／預約新機／新機每日轉盤
   - 儲值：新遊禮包／新遊階段式禮包
   - 押注：外贈（嚦咕「奢華外贈最高 35%」）
   - 排行榜：新遊龍虎榜

   **一台新機被榨出四種行為。** 別家是上了機台就結束。

### 主幹 3｜品牌與 IP：豪神的護城河，嚦咕沒有

這條是**豪神獨有**，也是最難複製的一條。

**吳宗憲代言** — 長期而非檔期，多支電視廣告。嚦咕是曾莞婷。

**大甲鎮瀾宮深度聯名 + 公益綁定：**
- 自 2008 年長期資助鎮瀾兒童家園，**累計捐款破 1,200 萬**
- 2026 遶境期間「刮好運」活動，部分營收轉公益基金
- 這在週報裡是一條**跨三個月、貫穿四種活動類型的主線**，不是零散檔期：
  - 4/09 大甲媽祈福平安包（儲值）
  - 4/13 儲值-大甲媽公益累儲、鎮瀾宮大富翁（押注）、大富翁-大甲媽繞境、押注-抽獎券
  - 4/13 憲哥刮刮樂-媽祖刮刮樂（代言人 × IP 疊加）
  - 5/02、5/14、5/26 大甲媽平安禮包
  - 6/07、6/19 大甲媽祈福禮包
  - 7/13、7/25 媽祖平安禮包

**為什麼這條難複製、也最有價值：**
1. **信仰 IP 對中高齡客層的說服力**，遠高於任何美術包裝
2. **公益綁定化解了 social casino 的道德負擔**，換來 PChome 等主流媒體正面版面——這是買不到的品牌背書
3. **一個 IP 撐三個月**，攤薄企劃成本，且累積玩家的期待節奏

嚦咕也做媽祖（寶石商城上架媽祖商品、儲值-媽祖祈福禮），但**深度差很多**，是跟進不是主導。嚦咕自己的 IP 是電影《嚦咕嚦咕新年財》聯名。

**時事熱點：** 世足競猜、棒球競猜、端午——兩家都做，這是基本盤不是差異點。

### 主幹 4｜留存節奏：豪神用「時段」切出回訪習慣

**人流活動檔數：豪神 21 檔全市場最高**（嚦咕僅 7、金好運 3）。

但關鍵是**定時制設計**，把一天切成多個必須回訪的時間點：

- 抽籤：0 點 / 12 點 / 18 點 / 21 點
- 支援金加領：0 點 / 12 點
- 火箭升空：19–24 點
- 紅包牆生肖奪寶：12–14 點 / 20–23 點
- 每日登入領足球幣：0 / 12 / 18 / 21 點

嚦咕對應的是「鴻包樂翻天 18-20；20:30-22:30」，只有兩個時段。

**「翻身支援金」機制** — 給輸光的低消費玩家續命，維持 DAU 池不崩。這是留存的底盤設計，不是活動。

> 討論題：我們的每日回訪誘因有幾個時間點？是「一天一次」還是「一天四次」？

### 主幹 6｜對照組反例：什麼是無效的

**王牌俱樂部（-24.9%）與老子有錢（+1.1%）—— 軍備競賽陷阱**
- 新機 45／41 檔、活動總量 157／120 檔，全市場最勤奮
- 新機 72% 同日開檔、押注 82% 同日開檔，互相貼身抄
- 結論：**活動量與新機量都不是成長變數，互抄只會稀釋**

**星城（-11.5%）—— 守成失敗**
- 仍有 33 檔新機、55% 市佔，但儲值活動僅 2 檔、排行榜 0 檔
- 靠規模與新機量守，變現設計幾乎空白
- 結論：**規模不能代替變現設計。星城是本波最大失血方（-262M）**

**錢街（+41.9%）—— 單一手法的天花板**
- 排行榜 41 檔，佔其活動 40%，極端押注單一機制
- 但月度劇烈波動：2026-03 衝到 19.6M，2026-07 跌回 12.8M
- 結論：**單一手法能起量但不穩，撐不出結構性成長**
